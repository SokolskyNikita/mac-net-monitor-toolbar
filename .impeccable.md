## Design Context

### Users
The owner uses this macOS menu-bar monitor to diagnose disrupted Zoom/Meet calls and distinguish local-router trouble from upstream network or web-access trouble.

### Brand Personality
Compact, clear, restrained. The user explicitly chose native macOS styling, clear typography, and restrained color.

### Aesthetic Direction
Native AppKit menus and system typography. Support both macOS appearances with semantic colors. Use readable informational views instead of disabled gray menu text. Avoid decorative dashboards, charts without data, and oversized metrics.

### Design Principles
- Make internet and local-router health easy to scan.
- Align values and group related measurements; keep technical detail secondary.
- Preserve the user's conditional visibility rules and compact menu-bar display.
- Use color as a secondary cue alongside numeric values and labels.
- Keep actions native, keyboard-accessible, and separate from readouts.
